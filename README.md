# scripts

Утилиты для разработки и сборки YoruOS.

## Будет содержать (Phase 6)

- `build-iso.sh` — обёртка над archiso
- `bump-version.sh` — обновление версии во всех репозиториях
- `check-license.sh` — линтер лицензий
- `release.sh` — релизный пайплайн (теги, артефакты, объявления)
- `dev/` — локальные dev-tools

## Язык

Bash + POSIX-совместимый shell. Никаких zsh-only фич.
